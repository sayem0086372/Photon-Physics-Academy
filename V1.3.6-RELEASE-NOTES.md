# Photon Physics Academy v1.3.6 — Store SMS & Bangla Wallet Instructions

## Changes
- After an administrator verifies a bKash/Nagad payment, a dialog offers to send a payment-confirmation SMS to the customer's phone number.
- The SMS message is editable; SMS is only sent after the administrator presses **Send SMS**. **Skip SMS** closes the dialog without sending.
- bKash and Nagad checkout instructions are clearer and written in Bangla while retaining familiar terms such as Payment, App, Send Money, Order, Total Amount, Transaction ID / TrxID, Admin, and Pending.
- Pending-payment filter/counter now includes pending/rejected bKash and Nagad payments as well as Cash on Delivery orders awaiting collection.
- Package version updated to 1.3.6.

## Database / data preservation
- The live store catalog was reset: `store_books` is now empty, and its inventory movement rows were cleared. Historical order and order-item snapshots were preserved; old order item `book_id` references were set to null.
- `store_orders`, `store_order_items`, coupon tables, store admin membership, and academy data were not cleared.
- The 13 `batches` rows were preserved. No Private Coaching Batch data was deleted.
- No new database migration is required for the frontend changes. SMS sending depends on the already configured `sms-gateway` Supabase Edge Function and its provider configuration.

## Validation
- ZIP archive integrity checked.
- Production build was not verified because `npm install` repeatedly timed out in this environment. Run `npm install` and `npm run build` in a network-enabled environment before deploying.
