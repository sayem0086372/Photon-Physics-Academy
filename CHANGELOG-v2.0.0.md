# Version 2.0.0 — WordPress Restoration

## Included in this development milestone
- Homepage notice categories and detail modal.
- Animated homepage statistics.
- Interactive classroom gallery lightbox.
- Admission inquiry form with server-side validation and WordPress admin storage.
- Footer Admin Login shortcut.
- Floating two-book hero for the WooCommerce store catalogue.
- Notice category taxonomy.
- PHP lint and installable package workflows enabled for this branch.

## Not yet included
Student and batch management, fee/payment processing, SMS gateway, results/exams, complete legacy admin interface, and the full legacy store management and payment-verification workflow remain in development. Do not deploy this milestone as a complete replacement for the old application.
