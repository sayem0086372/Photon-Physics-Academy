# Photon Physics Academy — v1.1.8

## Payments improvements
- The billing month selector now includes all twelve months, so staff can record overdue fees for earlier months rather than only October–December.
- Added a billing-year selector so outstanding fees from previous years can also be recorded.
- Added a searchable student picker that searches student name, student ID, class, and student/guardian phone numbers.
- The payment ledger month/year filters now cover all months and available years.

## Notes
- This is a frontend source update. No database migration is required for these UI changes.
- The website still needs to be rebuilt and redeployed to Netlify for the changes to appear on the live site.
